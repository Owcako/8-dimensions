# Success Metrics

- Players understand the job loop within one tutorial job
- Players feel the city is memorable and difficult in a good way
- Players can describe meaningful differences between cars
- Players want “one more shift”

- Core loop is playable end-to-end
- No blocker bugs in accepting and completing jobs
- At least famous Chongqing districts are functional

# Non-Goals

This game must not become:
- A pure racing game
- A generic city sandbox with no work identity
- A “car showroom” with shallow driving purpose
- A giant feature swamp where core driving work is weak
